# Plugin reference overrides

Drop a file named `<plugin_id>.md` here to append hand-written prose to
the corresponding auto-generated reference page. Useful for worked
examples, gotchas, or links to tutorials.

For example, `fpocketweb.md` would be appended (under a "Notes" heading)
to the page generated for the pocket-detection plugin.

These overrides are tracked in git; the generated reference pages are
not.
